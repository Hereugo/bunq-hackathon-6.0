# Creativity & Innovation [30%]

Originality of the idea. Novel application of AI agents or Bunq API

- [ ] Idea is original and stands out from common solutions
- [ ] Demonstrates a novel use of AI agents
- [ ] Innovative application of the Bunq API
- [ ] Introduces a fresh approach to solving a known problem
- [ ] Inspires new possibilities for banking or financial tools
- [ ] Combines technologies or concepts in an unexpected yet effective way


# Technical Execution [30%]

How well is the agent/application built? 

- [ ] Core functionality is complete and works as intended
- [ ] Application is stable and handles errors gracefully (robustness)
- [ ] Clever or efficient use of tools, libraries, or APIs
- [ ] Code quality is clean, organized, and maintainable
- [ ] Demonstrates thoughtful architecture or modular design
- [ ] Includes appropriate handling of edge cases or exceptions

# Impact & Usefulness [20%]

Does the solution solve a real problem? Does the solutoin create a significant value? Is the solution fun?

- [ ] The core problem(s) described is relevant to users
- [ ] The solution's value is clearly stated (e.g. it saves time, reduces stress, etc)
- [ ] The solution's impact significance is clearly stated (e.g. how many people the solutions helps, how the solution improves the experience)
- [ ] The solution's innovative/unique aspects are highlighted
- [ ] (Optional) The solution is fun or delightful.
